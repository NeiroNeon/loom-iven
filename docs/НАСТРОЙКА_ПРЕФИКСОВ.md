# Loom Iven — префиксы-плашки и чат (LuckPerms + TAB + EssentialsX)

Редакция 2.0 (server-pack v1.8.0). Принцип: **ник в чате и над головой — всегда
белый и нейтральный**, а принадлежность игрока показывается отдельной
**плашкой-префиксом** с названием привилегии. Плашка одна и та же в трёх местах:

| Место            | Чем показывается                          | Пример                  |
|------------------|-------------------------------------------|-------------------------|
| Чат              | EssentialsX `{PREFIX}` в формате чата     | `[Хранитель] Мира: привет` |
| Над головой      | TAB `tagprefix` (scoreboard-teams)        | `[Хранитель] Мира`      |
| Таб-лист (TAB)   | TAB `tabprefix`                           | `[Хранитель] Мира`      |

## 1. Схема плашек

Цвета плашек совпадают с лестницей активности LoomCore:

| Группа LuckPerms | Плашка                | Вес  | Кто                              |
|------------------|-----------------------|------|----------------------------------|
| `bot`            | `[Бот]` тёмно-серый   | 5    | технические боты                 |
| `default`        | `[Новичок]` серый     | 10   | все новые игроки (0 ч)           |
| `resident`       | `[Постоялец]` аква    | 20   | 24 ч (аукцион открывается)       |
| `keeper`         | `[Хранитель]` золотой | 30   | 120 ч (ивенты+, участки)         |
| `legend`         | `[Легенда]` лиловый   | 40   | 360 ч (ключи за часы)            |
| `sortannik`      | `[Соратник]` зелёный  | 45   | донат-привилегия 1               |
| `mecenat`        | `[Меценат]` бирюза    | 55   | донат-привилегия 2               |
| `patricij`       | `[Патриций]` синий    | 65   | донат-привилегия 3               |
| `fantom`         | `[Фантом]` фиолетовый | 75   | донат-привилегия 4               |
| `mentor`         | `[Ментор]` зелёный    | 90   | Старожил (336 ч), наставник      |
| `events`         | `[Ивенты]` фиолетовый | 100  | ивент-менеджер (`loom.admin`)    |
| `moderator`      | `[Модер]` синий       | 110  | модератор (`loom.admin`)         |
| `admin`          | `[Админ]` красный     | 120  | администратор (`loom.admin`)     |
| `owner`          | `[Владелец]` тёмно-красный | 130 | владелец проекта (`loom.owner`) |

Вес (`prefix.<вес>`) нужен, чтобы у сотрудников плашка должности перекрывала
плашку игрового ранга (игрок `Мира` может быть одновременно `keeper` и `moderator`).

Формат каждой плашки — `&8[&<цвет>Название&8]&r `:
тёмные скобки `&8` создают «рамку», цветное название — привилегия, `&r `
сбрасывает цвет, поэтому **ник после плашки остаётся белым** в любом месте.

## 2. Применить за один раз (вставить в консоль сервера)

Готовый список команд лежит в корне сервер-пака: **`НАСТРОЙКА_ПРЕФИКСОВ.txt`**.
Команды идемпотентны — их можно запускать повторно (перезапись префикса).

```mcfunction
lp group bot meta setprefix 5 "&8[&8Бот&8]&r "
lp group default meta setprefix 10 "&8[&7Новичок&8]&r "
lp group resident meta setprefix 20 "&8[&bПостоялец&8]&r "
lp group keeper meta setprefix 30 "&8[&6Хранитель&8]&r "
lp group legend meta setprefix 40 "&8[&dЛегенда&8]&r "
lp creategroup sortannik
lp group sortannik meta setprefix 45 "&8[&2Соратник&8]&r "
lp creategroup mecenat
lp group mecenat meta setprefix 55 "&8[&3Меценат&8]&r "
lp creategroup patricij
lp group patricij meta setprefix 65 "&8[&9Патриций&8]&r "
lp creategroup fantom
lp group fantom meta setprefix 75 "&8[&5Фантом&8]&r "
lp creategroup mentor
lp group mentor meta setprefix 90 "&8[&2Ментор&8]&r "
lp creategroup events
lp group events meta setprefix 100 "&8[&5Ивенты&8]&r "
lp creategroup moderator
lp group moderator meta setprefix 110 "&8[&9Модер&8]&r "
lp creategroup admin
lp group admin meta setprefix 120 "&8[&cАдмин&8]&r "
lp creategroup owner
lp group owner meta setprefix 130 "&8[&4Владелец&8]&r "
lp group owner parent add admin
```

Движение по лестнице (Новичок → … → Легенда) выполняет плагин **LoomPlaytimeRanks**:
он сам делает `lp user <ник> parent set <группа>` при достижении 24/120/360 часов
(маппинг — в `plugins/LoomPlaytimeRanks/config.yml`). Плашка обновляется сразу
после повышения; TAB подхватывает её в течение секунды.

## 3. Что уже настроено в server-pack (правки v1.6.1)

### 3.1 EssentialsX — `plugins/Essentials/config.yml`

```yaml
  format: '{PREFIX}&f{DISPLAYNAME}&7: {MESSAGE}'
```

- `{PREFIX}` — плашка из LuckPerms (через Vault-хук; Vault и LuckPerms уже в паке).
- `&f` перед `{DISPLAYNAME}` и `&7:` — ник всегда белый, двоеточие серое.
- `add-prefix-suffix` оставлен **выключенным** (иначе префикс задвоится:
  Essentials добавит его к displayName, а `{PREFIX}` выведет его же второй раз).
- `change-displayname: true` — отображаемое имя = игровой ник, без цвета.

### 3.2 TAB — `plugins/TAB/config.yml` (сортировка таб-листа)

```yaml
  sorting-types:
    - "GROUPS:owner,admin,moderator,events,mentor,fantom,patricij,mecenat,sortannik,legend,keeper,resident,novice,bot,default"
    - "PLACEHOLDER_A_TO_Z:%player%"
```

Сначала администрация, затем игроки — по убыванию лестницы, внутри ранга по алфавиту.

### 3.3 TAB — `plugins/TAB/groups.yml`

```yaml
_DEFAULT_:
  tabprefix: "%luckperms-prefix%"
  tagprefix: "%luckperms-prefix%"
  customtabname: "%player%"
  tabsuffix: "%luckperms-suffix%"
  tagsuffix: "%luckperms-suffix%"
```

`scoreboard-teams.enabled: true` (уже включён) — это и есть механизм, рисующий
плашку **над головой** игрока. Удалены декоративные секции-примеры (`Player:`,
`per-world.world1`), которые могли перекрыть префиксы LuckPerms.

### 3.4 Чат — LoomCore (v1.8)

С v1.8 формат чата рендерит сам **LoomCore** (`ChatFormat`, событие AsyncChatEvent,
Paper): плашка LuckPerms → белый ник → серое двоеточие → сообщение. Работает без
модуля EssentialsXChat и одинаково для Java и Bedrock (Geyser передаёт чат как есть).
Формат EssentialsX из §3.1 остаётся запасным (используется, только если LoomCore выключен).

## 4. Проверка

1. В релизе v1.8 группы с плашками уже лежат в `plugins/LuckPerms/global-groups.yml` —
   LuckPerms (storage yaml) подхватит их при первом старте; команды из §2 нужны
   только для ручного восстановления или правки в консоли.
2. `lp user <ник> parent set keeper` → зайдите в игру:
   - над головой: `[Хранитель] Ник`;
   - в чате: `[Хранитель] Ник: сообщение`;
   - в табе: строка с плашкой, отсортирована между keeper-игроками.
3. `/lp editor` — быстрая визуальная проверка групп и меты.

## 5. Английский вариант плашек (опционально)

Плашка в LuckPerms одна на группу, язык игрока ей не меняется. Для двуязычной
подачи используйте короткие нейтральные подписи, читаемые на обоих языках,
например: `[Novice] / [Новичок]` → `[Novice|Новичок]`. Альтернатива — оставить
русские плашки (сервер русскоязычный по умолчанию) и выдавать английским игрокам
группы-двойки `resident-en` с той же пермиссионной матрицей и плашкой `[Resident]`
(копия прав: `lp group resident-en clone resident`).
