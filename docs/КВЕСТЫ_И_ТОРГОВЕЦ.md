# КВЕСТЫ И ЗАКАЗЫ — LoomTrader 1.0.0 (новое в v1.6)

## 1. НПС-торговщица «Ивлия»

**Кто это:** житель-НПС без ИИ (не бродит, не торгуется ванильно, бессмертный, не деспавнится),
с именем над головой. Правый клик — открыть доску заказов (GUI).

**Установка:** админ встаёт на нужное место на спавне → `/торговец spawn`.
Позиция и UUID сохраняются в `plugins/LoomTrader/data/trader.yml`; после рестарта НПС
восстанавливается автоматически (если чанк выгружен — при первой проверке тикера). Убрать: `/торговец remove`.
Автоспавн из конфига: секция `npc:` в `plugins/LoomTrader/config.yml` (`y: -1` = не спавнить автоматически).

**Защита:** урон отменён (invulnerable + обработчик), подбирать предметы не может, коллизии выключены.
Двигаться/переносить НПС нельзя (житель без ИИ + сохранённый UUID).

## 2. Дейлики (ежедневные заказы)

### Правила
- Каждый день в **00:00** доска получает **10 заказов** из пула **59** — выбор детерминированный
  (seed = дата), поэтому **у всех игроков доска одинаковая**.
- Каждый заказ сдаётся **1 раз в день на игрока** → физический лимит **≤ 10 в сутки**.
- Сдача: клик по заказу в доске (или `/квесты сдать <id>`). Проверяется инвентарь: достаточно предметов —
  они изымаются, монеты начисляются мгновенно (+звук). Не хватает — покажет «нужно X, у вас Y».
- Названия предметов, категорий и интерфейс — на языке игрока (RU/EN).
- В лоре каждого заказа: «Нужно: N × предмет», «У вас: N / M», «Награда: X монет», категория, статус.

### Баланс (почему квесты выгодно брать)
```
награда = количество × базовая(рыночная) цена × бонус 1.25–1.4   (округление до 5)
```
Бонус — «зарплата за доставку»: сдав заказ, игрок получает на 25–40% больше, чем стоил бы товар.
Чем выше риск/сложность (Несская крепость, Край, варка зелий II уровня, карты сокровищ) — тем выше бонус.
Глобальный множитель: `daily.reward-multiplier` в config.yml (1.0 = базовый баланс).

### Примеры заказов (полный пул в QuestPool.java)
| id | Заказ | Награда | Категория |
|---|---|---|---|
| wheat | 1024 пшеницы | 110 | ресурсы |
| iron | 192 железных слитка | 840 | ресурсы |
| diamond | 32 алмаза | 1165 | ресурсы |
| pearl | 32 жемчужины Края | 500 | ресурсы |
| ghast | 16 слёз гаста | 475 | ресурсы |
| honeycomb | 128 сот | 90 | ресурсы |
| pot_heal2 | 6 зелий исцеления II | 325 | зелья |
| pot_fire | 8 зелий огнестойкости | 380 | зелья |
| pot_reg2 | 6 зелий регенерации II | 360 | зелья |
| ench_book | 4 зачарованные книги (любые) | 600 | предметы |
| gapple | 16 золотых яблок | 730 | предметы |
| heart_sea | 2 сердца моря | 810 | предметы |
| sponge | 16 губок | 520 | предметы |

**Проверка зелий** — строго по типу (`strong_healing`, `fire_resistance`, …), вода и «пустышки» не считаются.
**Проверка книг** — только действительно зачарованные (`hasStoredEnchants`).
Именованные/необычные предметы обычных материалов считаются на общих основаниях.

### Команды
| Команда | Кто | Действие |
|---|---|---|
| `/квесты` (алиасы `/quests`, `/дейлики`, `/dailies`) | все | открыть доску |
| `/квесты сдать <id>` | все | сдать по id |
| `/квесты список` | все | доска текстом |
| `/квесты лог` | все | сданное за сегодня |
| `/торговец spawn` / `remove` / `реролл` / `reload` | админ | управление НПС и доской |

## 3. НЕДЕЛЬНЫЙ ЗАКАЗ (глобальный квест на весь сервер)

### Суть
Каждый **понедельник 00:00** автостарт из ротации (config: `order.rotation`, формат `МАТЕРИАЛ:цель:фонд`):

| Материал | Цель | Фонд |
|---|---|---|
| WHEAT | 2 000 000 | 20 000 монет |
| CARROT | 1 500 000 | 18 000 |
| SUGAR_CANE | 1 200 000 | 18 000 |
| COAL | 500 000 | 25 000 |
| IRON_INGOT | 200 000 | 30 000 |

(номер ISO-недели выбирает пункт ротации; админ может в любой момент запустить свой заказ).

### Участие
- Сдача: `/заказ сдать <кол-во>` или `/заказ сдать все` — предметы уходят из инвентаря, вклад фиксируется.
- Прогресс: **boss-bar** для всех онлайн + оповещения на вехах **25 / 50 / 75%**.
- Статус: `/заказ` (цель, собрано, %, время, ваш вклад, ваша доля, прогноз выплаты). Топ: `/заказ топ`.

### Выплаты (математика)
```
выплата_игрока = floor(фонд × вклад_игрока / сумма_всех_вкладов)
минимум: 1 монета, если вклад > 0 (выплаты идут от большего вклада, пока хватает фонда)
```
- **Цель достигнута** → заказ закрывается сразу, фонд делится в тот же момент.
- **Срок вышел без цели** → фонд всё равно делится по долям (усилие не пропадает).
- **Отмена админом** (`/заказ cancel`) → без выплат (предметы уже израсходованы на цель).
- Объявление итогов: общий broadcast + топ-5 вкладчиков + личное сообщение каждому онлайн-получателю.

### Пример (пшеница, фонд 20 000, собрано 1 000 000)
| Игрок | Вклад | Доля | Выплата |
|---|---|---|---|
| Стазис | 200 000 | 20% | 4 000 |
| Мира | 50 000 | 5% | 1 000 |
| Тимоша | 2 | 0.0002% | 1 (минимум) |

Фонд не «печатается» и не «сгорает»: сумма выплат = фонд.

### Отличие от «Общего сбора» (LoomProgress §3)
| | Общий сбор | Недельный заказ |
|---|---|---|
| Что собирают | монеты | предметы |
| Кто запускает | админ вручную | автоматически каждую неделю |
| Фонд | 120% собранного (казна добавляет 20%) | фиксированный (задан при старте) |
| Ограничения доли | 105–150% своего вклада («Безубыточный участник») | нет — строго пропорционально |
| Недобор | возврат вкладов | фонд всё равно делится по долям |

## 4. Конфиг (plugins/LoomTrader/config.yml)

```yaml
npc:        # имя, позиция автоспавна (y: -1 = ждать /торговец spawn)
daily:
  count: 10             # заказов в сутки (макс. 59)
  reward-multiplier: 1.0
order:
  auto-weekly: true     # автостарт по понедельникам
  rotation:             # МАТЕРИАЛ:цель:фонд
    - "WHEAT:2000000:20000"
    - ...
```

## 5. Данные
- `plugins/LoomTrader/data/trader.yml` — НПС (UUID+координаты), доска дня, сдачи игроков (чистка: хранится только сегодня).
- `plugins/LoomTrader/data/order.yml` — активный заказ (материал, цель, собрано, фонд, дедлайн, вклады, веха).
