# Loom Iven v1.8.0

Кроссплатформенный Minecraft-сервер (Paper 26.3, Java 25+): выживание + SMP.
Java-клиенты 26.x (ViaVersion/ViaBackwards) и Bedrock-клиенты (Geyser + Floodgate).
Смоук-тест: **30/30 OK**, boot 42 c, 23 плагина.

## Что в релизе

**5 собственных плагинов (1.8.0):**
- **LoomCore** — монеты, RU/EN-локализация на игрока, лестница активности (Новичок → Постоялец → Хранитель → Легенда, далее Ветеран/Старожил/Виртуоз/Икона), анти-АФК, чат-плашки привилегий, GUI-меню `/меню` и профиль `/профиль`, HUD-скорборд с логотипом, админ-панель в GUI.
- **LoomPlaytimeRanks** — наигранные часы, синхронизация групп LuckPerms.
- **LoomAuction** — аукцион с Постояльца: шаг 5%, лот 48 ч, анти-снайпинг, комиссия, админ-модерация в GUI.
- **LoomProgress** — ивенты, 36 ачивок, сезонный пропуск **по реальным суткам** (обе ветки, 30 дней, хроно-восстановление), косметические ключи, менторы, зал славы, торговый квартал, «Общий сбор» по правилу «Безубыточного участника» (фонд 120%, зажим 105–150%, возврат при <50%).
- **LoomTrader** — НПС-торговец Ивлия (игрок-НПС со скином): дейлики ≤10/день из пула 59, недельный заказ с фондом по долям вклада, Bedrock-формы доски.

**GUI-каркас**: каждая логическая команда — предмет в GUI с лором и статистикой; клик открывает следующий GUI; пустые ячейки — тонированное стекло; админ-вкладка скрыта без `loom.admin`. Java — сундуки, Bedrock — нативные формы Floodgate.

**Привилегии**: 14 групп LuckPerms с плашками (лестница + донат-привилегии с льготами + персонал), смена прямо в игре через админ-GUI.

## Ассеты

- **server-pack.zip** — готовый сервер: Paper 26.3-231 + 23 плагина + настроенные конфиги (LuckPerms-сид, TAB, Geyser floodgate, Essentials). Распаковать, `java -jar paper-26.3-231.jar` (Java 25+). Мир генерируется при первом старте.
- **sources-and-scripts.zip** — исходники 5 плагинов + скрипты сборки/релиза/смоука (дублирует содержимое репозитория на момент тега).
- **site.zip** — статический сайт сервера (9 страниц, RU/EN, две темы). Также доступен в репозитории в `site/`.
