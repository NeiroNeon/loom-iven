# Loom Iven v1.8.1

Релиз-исправление к v1.8.0. Кроссплатформенный Minecraft-сервер (Paper 26.3, Java 25+):
выживание + SMP, Java-клиенты 26.x и Bedrock (Geyser + Floodgate). Смоук-тест: **30/30 OK**, boot 41 c, 23 плагина.

## Исправлено

- **Дублирующее право `loom.admin`**: объявление удалено из plugin.yml LoomAuction, LoomProgress и
  LoomTrader — единственный владелец права LoomCore. Предупреждения Bukkit
  «tried to register permission 'loom.admin' but it's already registered» при загрузке исчезли.
- **Имя НПС приведено к каноничному «Ивлия»** во всех текстах:
  - сайт, RU: 5 мест (вопрос FAQ, заголовки разделов, карточка квестов) + падежи
    («дейлики Ивлии», «доску заказов Ивлии»);
  - сайт, EN: Ivlly/Ivly → **Ivlia** (10 мест), «where do I find him?» → «her»;
  - LoomTrader: plugin.yml (description) и config.yml (имя НПС «странствующая торговщица», комментарий доски).
- Все 5 плагинов пересобраны как **1.8.1**.

## Аудит перед релизом
