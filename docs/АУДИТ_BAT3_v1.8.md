конфиги `server-pack/plugins/`, релиз `download/loom-iven-v1.7.0/`.

## 1. Критические баги (найдены аудитом)
1. 🔴 Пропуск: день = счётчик релогов (`touchDay()` на каждый join, без дат). 30 релогов = все 60 наград.
2. 🔴 LoomAuction: лоты удаляются из `lots` без переноса в `detached` → `/ah claim` теряет предметы.
3. 🔴 Geyser `auth-type: online` при Floodgate → Bedrock-вход закрыт.
4. 🔴 LuckPerms пуст (только `default`): скрипт префиксов не выполнен, плашки не работают.
5. 🔴 Чат-префиксы неактивны: модуль EssentialsXChat не установлен.
6. 🟠 Реролл торговца no-op (seed = дата); 7. 🟠 недельный заказ самоперезапускается в той же неделе;
8. 🟠 награды ивентов игнорируют конфиг (списки vs double); 9. 🟠 `/ментор код` заблокирован для новичков;
10. 🟠 `/монеты топ` не реализован; 11. 🟠 обход гейта аукциона через меню + buyout без лестницы;
12. 🟠 страница 53 аукциона уходит за пределы; 13. 🟠 `/сбор start` стирает вклады без возврата;
14. 🟠 миграция косметики пропуска не реализована; 15. 🟠 двойной ключ на днях 7/14 (f+d);
16. 🟠 HUD-хардкод «/10»; 17. 🟡 нет пагинации MenuGUI (>45 действий обрезаются);
18. 🟡 Bedrock-паритет форм неполный; 19. 🟡 пустые ячейки GUI не заполнены;
20. 🟡 мёртвый код (CLAIMS, gui.prev/next, lang-дубли LoomAuction, npc.* конфиг LoomTrader, access-order игнор);
21. 🟡 RCON-пароль открытым текстом (предупреждение в README); 22. 🟡 казна квартала = эмиссия (документируем).

- Адрес сайта в подвале таба: **loom-iven.ru**.
- НПС Ивлия: **игрок-НПС** (ProtocolLib, скин рыжеволосой торговки), переименование «Ивлий»→«Ивлия».
- Сутки пропуска: **личная активация** (первый вход после старта сезона; день N открыт ровно 24 ч).
- Хроно-предмет (восстановление сгоревшего дня): **в наградах донат-ветки** дней 5/10/15/20/25/30.
- Донат-привилегии Соратник/Меценат/Патриций/Фантом: **создать с льготами** (+лоты аукциона, скидка комиссии, пресет сбора 10 000, еженедельный ключ).
- Филлер GUI: **BLACK_STAINED_GLASS_PANE** без имени, клики отменены.
- Чат-формат: **в LoomCore** (плашка LuckPerms + белый ник), не EssentialsXChat.
- Скорборд: **обновление 1 сек**.
- Принято по умолчанию: «Пропуск Толе»=«пропуск тоже»; владелец = группа owner + право loom.owner;
  правила Общего сбора (120%/105–150%/<50%) не меняются; миграцию косметики реализовать честно;
  косметика без частиц (статусы в GUI); Discord-документы в релиз v1.8 не включать; релиз v1.8.0.

## 4. Архитектура пропуска v1.8 (утверждено)
- Хранение на игрока: passStart (epoch ms активации), passDonate, passClaimed[fN/dN], chrono (шт),
  restored (список восстановленных дней), prevSeasonCosmetic (миграция), weeklyKeyDay (день еженедельного ключа).
- day(uuid) = clamp((now − passStart)/86400e3) + 1, максимум season.days.
- Окно дня N: [passStart+(N−1)·24ч, passStart+N·24ч). Клейм только в окне своего дня.
- Пропущенное окно (не заклеймил до конца N-го) → день сгорает; хроно-предмет (клик по сгоревшему дню,
  chrono>0) восстанавливает и сразу выдаёт награду. Хроно выдаётся с донат-клеймов дней 5/10/15/20/25/30.
- Донат-ветка: покупка 25 000; ключи на днях кратных 7 — только в бесплатной ветке (фикс двойных);
  сезонная косметика с 15-го дня (донат); миграция: косметика прошлого сезона → бесплатная ветка с 25-го дня.
- GUI: страницы 1–15 / 16–30 × ветка free/donate (тумблер), лор дня: награды, статус, окно, оставшееся время.
